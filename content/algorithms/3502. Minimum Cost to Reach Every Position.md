https://leetcode.com/problems/minimum-cost-to-reach-every-position/description/

**문제 요약**

맨 뒤에서 시작해 다음 조건에 따라 각 인덱스로 이동하는 최소 비용을 구하는 문제

- 앞 인덱스로 갈때는 cost를(cost[i]) 지불해야 한다.
- 뒤쪽으로 이동하는건 무료이다.

---

### 풀이

**직관**

뒤에서 출발하는 조건을 고려했을때,

앞 인덱스 어딘가로 이동하고 나면 뒤로갈때는 cost가 안들기 때문에,

갈 수 있는 범위내에서 가장 싼 cost인 곳으로 이동한뒤 나머지는 뒤로 감으로써 해결하면 된다.

이를 바탕으로, 맨 첫 위치부터 이동해야 할 곳 사이에 가장 비용이 싼 곳을 찾는다면, 거기로 이동한뒤 뒤로만 가면 된다는 결론이 나온다.

```python
class Solution:
    def minCosts(self, cost: List[int]) -> List[int]:
        minCost = cost[0]
        res = []
        for c in cost:
            minCost = min(minCost, c)
            res.append(minCost)
            
        return res
```

시간복잡도: O(n)
