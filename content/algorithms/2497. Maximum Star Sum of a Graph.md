문제 요약

:그래프 문제. 각 노드가 중심 노드라고 가정할때, 중심과 연결된 최대 k개 노드로 구성된 서브그래프를 star graph라고 한다. star graph의 합계를 구했을때 나올 수 있는 최대값을 구하는 문제

- 입력값1: 각 노드가 어떤 노드랑 연결된지 정보를 담은 이중배열 edges
- 입력값2: 각 노드가 가진 값을 나타내는 배열 vals
- 입력값3: 합계를 구할 star graph의 노드 개수 k

---

### 풀이

**직관**

- edges를 돌면서, 각 인덱스가 중심 노드라고 생각했을때의 구조를 만들어내기 위해 딕셔너리로 dict={ 0: [1, 3, 4] } 와 같은 구조를 만든다.
- 만든 딕셔너리에 저장된 value들의 합계가 가장 커지는 값을 구한다.

**풀이 과정**

- 고려 사항1: 합계를 구할때 후보중에 음수는 굳이 안써도되지만, 주어진 노드들이 음수밖에 없다면 최대값이 음수일것이라 어쩔 수 없이 음수를 뱉어야 한다. → 초기값을 음의 무한대로 설정
- 고려 사항2: 노드의 인덱스랑, 노드의 실제 값이랑 헷갈리는데 잘 구분해야 한다.
- 고려 사항3: k개의 노드를 선택해서 합계에 포함시킬 수 있지만, 음수는 굳이 선택할 이유가 없기 때문에 이 부분 고려해야 한다.
- 고려 사항4: 합계를 구할때 중심 노드의 값은 무조건 포함인 것 기억.

```python
class Solution:
    # edges를 돌면서, 각 인덱스가 중심 노드라고 생각했을때. 이때 연결된 노드들로 가장 큰 합계를 만들 수 있는 로직이 필요
    def maxStarSum(self, vals: list[int], edges: list[list[int]], k: int) -> int:
        node_dict = {i: [] for i in range(len(vals))}  # 모든 노드들(키) 각각 어떤 노드랑 연결되어있는지(값. 배열형태)
        res = float('-inf')  # 노드 합계 최대값이 음수일수도 있는 경우를 위해 음의 무한대로 초기값
        for node1, node2 in edges:
            # 음수는 나중에 더해봤자 소용없기 때문에 애초부터 딕셔너리에 추가 안함
            # value은, 아예 지금부터 노드 번호가 아닌 실제 값으로 추가함.
            if vals[node2] > 0: node_dict[node1].append(vals[node2])
            if vals[node1] > 0: node_dict[node2].append(vals[node1])

        for key, val in node_dict.items():
            sums = vals[key]  # 중심 노드의 값은 무조건
            sort = sorted(val, reverse=True)
            for n in sort[:k]:
                sums += n
            res = max(res, sums)
        return res
```

시간복잡도: O(n + E log E)
